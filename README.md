# pong-game-python

A classic Pong Game built with **Python** and **Turtle Graphics**.  
Two players control paddles to bounce the ball back and forth, aiming to score points when the opponent misses. The game recreates the nostalgic arcade experience with simple controls and score tracking.

---

## Project Overview

### 1. Project Structure
pong-game-python/
   - main.py              # Entry point to run the game
   - paddle.py            # Defines Paddle class (movement controls)
   - ball.py              # Defines Ball class (movement, collision detection)
   - scoreboard.py        # Handles score tracking and display

---

### 2. How to Execute
1. Clone the repository  
   git clone https://github.com/abhishekchouria-codes/pong-game-python.git

2. Navigate into the project folder  
   cd pong-game-python

3. Run the game  
   python main.py

---

### 3. Features
- Two-player paddle control for competitive play  
- Ball movement with realistic bounce mechanics  
- Collision detection with paddles and walls  
- Scoreboard to track points for each player  
- Lightweight, beginner-friendly arcade recreation  

---

### 4. Technologies Used
- Python 3  
- Turtle Graphics – for rendering and visuals  
- Object-Oriented Programming (OOP) principles  

---

### 5. Controls
- Player A: Use **W** (up) and **S** (down) keys to move the left paddle  
- Player B: Use **Up Arrow** and **Down Arrow** keys to move the right paddle  
- Ball bounces automatically; score increases when the opponent misses
